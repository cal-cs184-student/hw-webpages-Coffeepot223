Overview

In this homework, I explored geometric modeling by building Bezier curves and surfaces using de Casteljau's algorithm, manipulating triangle meshes via the half-edge data structure, and implementing Loop subdivision for mesh upsampling. This project gave me hands-on experience with the pointer operations required to safely modify mesh topology without breaking manifold properties.

Section 1: Bezier Curves and Surfaces

Part 1: Bezier Curves with 1D de Casteljau Subdivision

De Casteljau's algorithm is a recursive method used to evaluate Bezier curves by performing several consecutive linear interpolations between adjacent control points at a specific parameter. In my implementation, I ran a loop through the provided points array and computed the next level of intermediate points using the formula $p' = (1 - t)p_i + t p_{i + 1}$. Then, by storing these newly calculated points in a vector and returning it, the algorithm reduces the number of control points by one with each step until a single point lying directly on the curve is found.

Part 2: Bezier Surfaces with Separable 1D de Casteljau

De Casteljau's algorithm extends to Bezier surfaces through a separable 1D method, where we first evaluate a series of 1D Bezier curves along one single axis to generate a new set of intermediate control points. In my implementation, I evaluated each row of the given control point grid at parameter u to find these intermediate points. After that, I used that new array of points to evaluate a final 1D curve at the parameter v.

Section 2: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-Weighted Vertex Normals

To implement my solution, I looped through the half-edge data structure to iterate through all the non-boundary faces that are incident to a given vertex. For each face, I calculated the cross product of two of its edge vectors, which gives me a normal vector whose magnitude is twice the face's area, then I added this to an accumulated sum. Finally, I normalized the resulting sum vector to produce the smoothed Phong shading result.

Part 4: Edge Flip

To implement the edge flip operation, I first gathered all relevant data points, like half-edges, vertices, faces… from the two adjacent triangles before making any modifications. Next, I reassigned the pointers for every single element to match the post-flip configuration, while ignoring boundary edges. An implementation trick I used was mapping out the before-and-after states on paper to track each pointer to prevent any significant mesh errors.

Part 5: Edge Split

To implement the edge split function, I created a new vertex at the edge's midpoint along with the necessary new edges, faces, and half-edges in order to divide the two original triangles into four. During debugging, I encountered missing triangles and black background holes in my mesh because I incorrectly reassigned the origins of the outer boundary half-edges. Drawing a detailed before-and-after diagram allowed me to properly assign pointers to create a complete surface.

Part 6: Loop Subdivision for Mesh Upsampling

I implemented the loop subdivision function by first computing the updated positions for all original vertices and edge midpoints and storing them. Then, I split every original edge and flipped the newly created edges that connected an old and a new vertex, and updated all vertices to their calculated positions. I ran into a few infinite loops, and my main debugging trick was strictly using the isNew flags to avoid an infinite loop of splitting newly created edges.

After applying Loop subdivision, the meshes become much smoother, causing the mesh to become visibly more rounded. Additionally, we can reduce this smoothing effect on specific features by pre-splitting the edges near the sharp corners before subdividing the mesh. This caused higher vertex density, which in turn keeps the algorithm’s weighted averaging to keep the new positions much closer to the original, sharper geometry.

When repeatedly subdividing the cube, it becomes asymmetric because its faces are initially divided by single diagonals in alternating directions, which causes the looped subdivision weights to pull the vertices unevenly because of the biased topology. To fix this issue and ensure symmetric subdivision, I pre-processed the cube by splitting the diagonal edge across every face to create a symmetric X pattern on all six sides. This balances the vertex degrees and edge connections, allowing the weighted averaging to distribute evenly and maintain a more rounded shape as it upsamples.
